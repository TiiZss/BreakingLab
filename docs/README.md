# BreakingLab Planning Docs

## Purpose
This index groups the planning and governance documents that support the BreakingLab stabilization roadmap.

## Documents
1. `docs/plan-breakingLab-roadmap.md`
Public-facing roadmap document for the 60-90 day plan.

2. `docs/rfc-breakingLab-roadmap.md`
Short RFC-style summary of the decision, context, and guardrails.

3. `.github/prompts/plan-breakingLab.prompt.md`
Master strategic and operational planning prompt.

4. `.github/prompts/plan-breakingLab-execution.prompt.md`
Strict execution prompt for phased implementation work.

5. `.github/prompts/plan-breakingLab-compact.prompt.md`
Compact executive summary version.

6. `.github/prompts/plan-breakingLab-en.prompt.md`
English planning variant.

7. `docs/github-planning-conventions.md`
Conventions for labels, epics, issue structure, and PR expectations.

8. `docs/issue-batch-1.md`
First prioritized batch of issues ready to open.

9. `docs/planning-handoff.md`
Resume guide for the next working session.

10. `docs/workflow/MEMORY.md`, `docs/workflow/LEARNINGS.md`, `docs/workflow/decisions.md`
Hechos estables, lecciones y registro de decisiones del agente. El mapa que los ata está en `CLAUDE.md`.

## Recommended reading order
1. `docs/rfc-breakingLab-roadmap.md`
2. `docs/plan-breakingLab-roadmap.md`
3. `.github/prompts/plan-breakingLab.prompt.md`
4. `.github/prompts/plan-breakingLab-execution.prompt.md`
5. `.github/prompts/plan-breakingLab-compact.prompt.md`
6. `.github/prompts/plan-breakingLab-en.prompt.md`
7. `docs/github-planning-conventions.md`
8. `docs/issue-batch-1.md`
9. `docs/planning-handoff.md`

## Usage
1. Use the RFC and roadmap to understand direction.
2. Use the prompts to guide planning and execution.
3. Use the conventions document when creating GitHub artifacts.
4. Use the issue batch document to seed the first implementation wave.
5. Use the handoff document to resume quickly in a later session.
