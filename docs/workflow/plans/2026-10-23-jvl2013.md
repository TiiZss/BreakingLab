La máquina nueva es `jvl2013`. El JVL que ya arranca en `127.0.0.1:9080` con `tiizss/jvl:latest` se queda como está.

El origen es https://github.com/TiiZss/JavaVulnerableLab, rama `master`, el texto del README la llama Java Vulnerable Lab 2013. La última release del repo es `v3.0.0`. El compose de ese repo pide `tiizss/jvl:v2.1.0` y `mysql:5.7`, y publica el `8080`. Esa imagen no se mezcla con `tiizss/jvl:latest`.

La aplicación espera MySQL en el host `mysql`, base `abc`, usuario y contraseña `root`. Si `/JavaVulnerableLab/` responde, se publica `tiizss/jvl-2013:2013`. MySQL sigue siendo `tiizss/mysql-5.7:5.7`. En el lanzador la dirección es `127.16.0.1:8080`.
