# Release 2.3.0

## Hecho

`v2.2.0` describe un solo stack `breakinglab`. `main` ya usa `breakinglab_<clave>`, guarda los clones en `labs/` y el compose del lanzador en `projects/`. El changelog deja eso en `[Unreleased]`. El README sigue en «Features (v2.2)» y `CLAUDE.md` llama submódulo a Vulpy 5.

## Cambio

- `[Unreleased]` pasa a `[2.3.0] - 2026-10-25`, con exploit.co.il, Vulpy 5 y el fin de línea LF.
- El README, `CLAUDE.md`, `MEMORY.md` y `decisions.md` cuentan el stack por máquina y el compose de `projects/`.
- Si ShellCheck del push queda en verde: tag `v2.3.0`, release en Gitea y después en GitHub.
