# Bricks 2.2

Fecha: 2026-10-22

La imagen `citizenstig/owaspbricks` usa un manifiesto v1 que containerd 2.1 rechaza. Bricks 2.2 (Tuivai) se descarga de SourceForge y se sirve con PHP 5.6, porque el código llama a `mysql_connect`. MySQL 5.7 guarda la base `bricks` con usuario `root` y contraseña `root`, como dice la instalación de sechow. La aplicación queda en `http://127.21.0.1/bricks/`.
